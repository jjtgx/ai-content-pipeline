# AI Content Pipeline · 最小可运行流水线

一条真实跑通的「AI 自动选题 → 生成初稿 → 排版发布」内容流水线。
适合放进简历 / 作品集的最小 AI 作品：**零第三方依赖，一条命令，产出完整文章 + 发布日志**。

```
选题 Agent → 初稿 Agent → 排版 Agent → 发布 Agent
```

## 为什么值得放进简历

| 能力 | 体现 |
| --- | --- |
| 工程拆解 | 把「写文章」拆成 4 个可自动化的阶段，而非让 AI 一把梭 |
| AI 应用 | 每个阶段是独立函数，可替换为 Claude Code / GPT / 飞书多维表格 |
| 真实交付 | 一次运行产出排版好的 HTML 文章 + 发布日志，不是 demo 片段 |
| 可复现 | 固定 `--seed` 即可复现选题，评审可自己跑 |

## 快速开始

```bash
# 仅需 Python 3.8+，无第三方依赖
python pipeline.py --seed 42
```

运行后产物在 `output/` 目录：

| 阶段 | 产物 | 内容 |
| --- | --- | --- |
| 1 选题 | `01-topic.md` | 选题卡：标题 / 领域 / 热度 / 角度 |
| 2 初稿 | `02-draft.md` | 结构化 Markdown 初稿 |
| 3 排版 | `03-final.html` | 公众号风格 HTML，可直接打开 / 截图 |
| 4 发布 | `04-publish.log` | 发布时间 / 链接 / 字数 / 耗时 |

打开 `output/03-final.html` 即可查看排版成品。

```

├── output/                  # 一次运行的全部产物
└── README.md
```

## 四阶段是怎么工作的

1. **选题 Agent**：从内置选题池（6 条候选，带领域 / 热度分 / 切入角度）按「热度分 + 随机扰动」加权自动选题，输出选题卡；
2. **初稿 Agent**：按固定文章结构（导语 / 小节 / 要点 / 金句 / 结尾）生成 Markdown 初稿；
3. **排版 Agent**：自写小型 Markdown 渲染器，转成公众号风格 HTML（封面 / 正文 / 引用块 / 代码块，纯内联样式，离线可看）；
4. **发布 Agent**：汇总发布时间、链接、字数、耗时，生成可追溯的发布日志。

## 升级路线

- 选题池 → 飞书多维表格，定时任务每天自动选题 + 生成初稿
- 初稿 → 真实 LLM 接口（Claude / GPT），模板保证结构，模型负责文笔
- 发布 → 公众号草稿箱 / 飞书文档，跑完自动创建在线文档
- 增加人工审核门，发布前必须过审
