这篇文章记录我做的第一个 AI 作品:一条「自动选题 → 生成初稿 → 排版发布」的内容流水线。它真实跑通了,产物是一篇排版好的公众号风格文章;代码只有 300 多行,零第三方依赖,任何人都能复现。

一、这个作品是什么

一句话:一条命令行流水线,输入一个随机种子,输出一篇排版好的文章 + 完整发布日志。

python pipeline.py --seed 42

全流程拆成四个阶段,每个阶段一个明确产物:

阶段Agent 职责产物
1 · 选题从选题池按「热度分 + 随机扰动」加权自动选题01-topic.md 选题卡
2 · 初稿按固定文章结构生成 Markdown 初稿02-draft.md 初稿
3 · 排版自写 Markdown 渲染器,转公众号风格 HTML03-final.html 成品
4 · 发布汇总发布时间、链接、字数,写发布日志04-publish.log 日志

二、为什么值得放进简历

它同时展示了四件事:

  • 工程拆解能力:把「写文章」拆成可自动化的四段,而不是让 AI 一把梭;
  • AI 应用能力:每个阶段都是一个可替换的 Agent 接口,可以换成 Claude Code、GPT、飞书多维表格;
  • 交付能力:一次运行产出完整可用的成品,不是 demo 片段;
  • 可复现性:固定 seed 即可复现选题,面试官自己就能跑。
金句:AI 写作不是「让 AI 替你写」,而是「让 AI 替你完成可自动化的部分」。

六、怎么复现(给面试官 / 给读者)

只需要 Python 3.8+,不需要装任何第三方库:

# 1. 下载项目(或从 GitHub 克隆)
# 2. 进入项目目录
python pipeline.py --seed 42
# 3. 打开 output/03-final.html 查看排版成品
# 4. 查看 output/04-publish.log 确认发布记录
项目目录结构
pipeline.py —— 流水线主脚本(四阶段,约 300 行)
output/ —— 运行产物:选题卡 / 初稿 / 排版 HTML / 发布日志 / 运行日志
assets/ —— 本文截图素材

七、下一步怎么升级

  • 把选题池接进飞书多维表格:用表格维护选题,定时任务每天自动选题 + 生成初稿;
  • 把初稿阶段换成真实 LLM 接口(Claude / GPT):模板保证结构,模型负责文笔;
  • 发布阶段接入公众号草稿箱 / 飞书文档:跑完自动创建在线文档;
  • 加一个人工审核门:发布前必须过一道人审,防止内容翻车。
